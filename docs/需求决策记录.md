## 0. 文档说明

本文与参考文档《云枢智学-需求文档.md》是**基线与覆盖**的关系：

- **参考文档 = 功能基线**：页面、字段、交互、状态流转、枚举、通用约定以它为准。
- **本文 = 决策与覆盖**：记录在基线之上新增、修改、或明确不做的内容。
- **冲突时以本文为准**；本文未提及的部分，按参考文档执行。

第 2 节是差异总表，第 4 节是逐节修改点，适合直接拿去改参考文档。

## 1. 项目概述

### 1.1 定位

面向学员的在线学习、刷题与 AI 面试平台，同时提供机构运营后台。系统形态为**单机构自用**，但因开放注册，对外呈现为公开产品。

### 1.2 学科

固定 **8 个 AI 方向**（与参考文档一致）：

1. AI 应用与智能体开发
2. AI 大模型开发
3. AI 具身智能机器人开发
4. AI 嵌入式_机器人开发
5. AI 测试
6. AI 运维
7. AI 视觉设计
8. AI 视频与短剧创作

> 原设想中的"Java 开发"不在本期范围内。

### 1.3 角色

| 端 | 角色 | 说明 |
|---|---|---|
| 学员端 | 游客、学员 | 游客仅可访问首页；其余页面需登录 |
| 管理端 | 超级管理员、内容审核、运营人员 | 沿用参考文档；原"教研"角色取消，内容由运营录入、内容审核把关 |

## 3. 已确认决策

### 3.1 产品定位与账号

| 决策项 | 结论 |
|---|---|
| 注册 | 开放自主注册；手机号 + 短信验证码 + 密码 |
| 登录 | 账号密码 / 手机验证码；第三方登录（微信 / QQ / GitHub） |
| 找回密码 | 三步流程（验证手机 → 重置密码 → 完成） |
| 安全频控 | 连续 5 次密码错误锁定 5 分钟；验证码 60 秒 1 次、每日 10 次；同一验证码失败 5 次失效 |
| 学员分层 | 不区分正式学员，注册即学员 |
| 游客可见 | **仅首页**；学习路线、题库、面试、个人中心均需登录 |
| 年龄门槛 | 注册勾选"已满 18 岁"，不强制验证 |
| 隐私同意 | 注册页强制勾选协议；协议须写明足迹、AI 处理答题与面试内容、**录音会被保存 90 天** |
| 录音单独同意 | 首次进入 AI 面试前，需单独同意录音；不同意则不可使用语音，可改用文字 |
| 账号注销 | 支持；软删除保留 30 天后彻底清除 |
| 账号禁用 | 后台可禁用，禁用后无法登录 |

### 3.2 内容结构

| 决策项 | 结论 |
|---|---|
| 层级 | 学科 → 阶段（题目挂阶段）；课程库独立；学习路线引用课程 |
| 路线归属 | 一条路线只属一个学科 |
| 课程 | 外链 B 站；课程库可被多条路线引用 |
| 题库 | 刷题题库、面试题库两套独立；题目必须挂阶段 |
| 题目必填项 | 阶段、类型、难度、**能力维度**、题干、选项、正确答案、解析 |
| 知识库 | 每个知识库绑定一个学科；仅支持 Markdown/文本，按标题切题，不做 AI 抽题 |
| 能力维度 | **全局 6 个，所有学科共用**：基础概念、技术深度、工程实践、问题分析、表达逻辑、项目经验 |

### 3.3 学习与进度

| 决策项 | 结论 |
|---|---|
| 学习足迹 | 记录点击跳转 B 站（课程 ID + 时间），保留 1 年 |
| 已学标记 | 学员在学习路线页手动点"标记已学"；已学课程数 = 手动标记数 |
| 学习天数 | 有任意活动（做题 / 面试 / 标记已学）的日期数 |
| 后台口径 | 可使用"已学课程数 / 标记率"；**禁止使用"学习时长"** |
| 继续学习 | 基于浏览器本地保存的练习进度，不使用服务端草稿 |

### 3.4 刷题与判分

| 决策项 | 结论 |
|---|---|
| 练习模式 | 顺序练习 + 随机练习 + 错题重练 |
| 判分方式 | **逐题即时批改**；已批改题目不可修改 |
| 解析 | 每题提交后即可查看该题解析，不再等待整卷 |
| 练习进度 | 浏览器本地持久化；换设备 / 清缓存即丢失 |
| 限时 | 不限时；仅记录用时 |
| 多选判分 | 漏选给部分分，错选 0 分；**满分才算对** |
| 简答判分 | AI 自动评分 + 评语；**必须配置采分点与分值** |
| 简答及格线 | **每题单独设，默认 60%**（按该题满分百分比） |
| 简答评分卡 | 分数、评语、采分点命中情况、参考答案 |
| 重复练习 | 每次为新记录，保留历史；练习记录保留 2 年 |
| 未作答处理 | 允许交卷时存在未作答题目；未作答题不计分、不进错题本 |

### 3.5 错题本

| 决策项 | 结论 |
|---|---|
| 收录 | 答错即进；简答题低于本题及格线即视为答错 |
| 掌握 | 连续答对 3 次自动标记"已掌握" |
| 手动操作 | 支持"标记已掌握"与"移除错题"，支持批量操作 |
| 状态 | 待复习 / 已掌握；已掌握置灰 |
| 错误等级 | ≥3 次高频易错、=2 次多次错误、1 次偶尔错误 |
| 重练 | 全部待复习错题混合重练；答对一次纠正进度 +1 |

### 3.6 AI 面试

| 决策项 | 结论 |
|---|---|
| 配置项 | 技术方向（8 学科）、难度（简单/中等/困难）、题数（3/5/8/10/15，默认 10）、单题超时 5 分钟 |
| 配额 | 每日 5 次，次日 0 点重置 |
| 抽题 | 按方向 + 难度筛选，**优先保证 6 个维度覆盖**；不足时随机补题；仍无题的维度标注"本场未考察" |
| 作答方式 | 文本输入；语音识别写入输入框；AI 消息语音播报（默认开启，可关闭） |
| 追问 | **不做** |
| 评分 | 每题 0–10 分，映射到 6 个能力维度；维度得分 = 该维度下题目得分的平均 |
| 录音 | 保存 90 天，仅用于学员回放；90 天后自动删除；不用于评分 |
| 表达维度 | 不从录音评语速/停顿；"表达逻辑"仅基于文字内容评分 |
| 报告保留 | 永久 |
| 历史对比 | 同方向 + 同难度，与最近一次对比；无历史时不显示该区块 |
| 报告内容 | 总分 + 6 维度分 + 逐题点评 + 优缺点 + 改进建议 + 能力提升建议 + 历史对比 + 查看回放 |
| 会话持久化 | 沿用参考文档：浏览器本地保存，可继续或重新开始 |

### 3.7 能力评价体系

| 决策项 | 结论 |
|---|---|
| 维度 | 全局 6 个，所有学科共用 |
| 刷题标注 | 每道题必标一个能力维度 |
| 面试标注 | 每道面试题必标一个能力维度 |
| 维度→内容映射 | 后台维护「维度 → 课程/阶段」，必填，供报告推荐复习内容 |
| 能力中心 | 独立页面；刷题雷达图 + 面试雷达图 + 综合图，分来源展示 |
| 综合图 | 两来源可用维度分的组合；具体权重见未决 |

### 3.8 管理后台

| 决策项 | 结论 |
|---|---|
| 角色 | 超级管理员 / 内容审核 / 运营人员；权限树 25 项（沿用参考文档） |
| 题库审核 | 沿用参考文档状态流转：待审核 → 已上架 / 已驳回；已上架 → 已下架 |
| 内容分工 | 运营录入内容，内容审核只审不改 |
| 新增模块 | 能力维度管理（6 个）、维度→内容映射、简答批改复核中心、知识库管理、能力中心数据源 |
| 学员管理 | 查看足迹/刷题/面试记录；启用/禁用/删除；导出 Excel |
| 导出 | 默认手机号脱敏；超管可申请明文导出；所有导出写操作日志 |
| 看板 | 用户（注册/日活/留存）、学习（访问量/已学标记数）、刷题（次数/正确率/错题分布）、面试（场次/均分/维度均分） |
| 导入 | 题库、课程均支持 Excel 批量导入 |

### 3.9 非功能与合规

| 决策项 | 结论 |
|---|---|
| 终端 | 响应式 Web，PC 为主、移动可用 |
| 规模 | 注册 < 5,000，日活 < 500 |
| AI 成本 | 面试每日 5 次/人；简答判分设每日额度（数值见未决） |
| 数据保留 | 足迹 1 年、练习记录 2 年、面试报告永久、录音 90 天 |
| 合规 | 注册同意、录音单独同意、注销与数据删除、导出脱敏、操作日志 |

## 8. 风险提示

| # | 风险 | 说明 | 缓解建议 |
|---|---|---|---|
| 1 | **内容工作量** | 8 个学科 × 阶段 × 题目 × 6 维度标注；每道简答题要配采分点与及格线 | 导入模板先行；采分点由参考答案半自动生成、人工确认 |
| 2 | 审核流程拖慢内容上线 | 运营录入后要等内容审核 | 小团队可让同一人兼任，但权限上仍需区分 |
| 3 | 录音合规 | 声纹属敏感个人信息 | 单独同意 + 90 天自动删除 + 隐私政策明示 |
| 4 | 抽题无法保证维度覆盖 | 题数可配 3，维度有 6 个 | 接受"本场未考察"标注，不虚构分数 |
| 5 | 本地进度丢失 | 换设备 / 清缓存即丢 | 在练习页提示"进度仅保存在本机" |
| 6 | AI 判分一致性 | 同一答案多次判分可能不同 | 强制采分点 + 保存采分点快照 + 人工复核 |
| 7 | 知识库切题质量 | 按标题切题依赖文档规范 | 提供切题预览与人工调整 |
| 8 | 维度标注遗漏 | 题目不标维度就无法进能力中心 | 设为必填 + 后台覆盖检查 |

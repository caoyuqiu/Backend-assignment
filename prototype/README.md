# 云枢智学 · 交互原型

基于 `docs/需求决策记录.md`（v0.2）实现的**纯前端可交互页面原型**。只还原交互与页面结构，不包含服务端逻辑、真实 AI 能力与真实数据存储。

## 打开方式

直接双击 `prototype/index.html`，用浏览器打开即可（无需安装、无需启动服务）。打开后首先进入**端选择页**，可选择「学员端」或「管理端」。

- 推荐 Chrome / Edge 最新版
- 支持通过本地静态服务打开，例如在 `prototype` 目录执行 `python -m http.server 8080`，再访问 `http://localhost:8080`
- 所有数据保存在浏览器 `localStorage`，换浏览器或清除缓存后回到初始演示数据

## 演示入口

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 端选择 | `index.html#/entry` | 打开页面后的默认首页，选择学员端 / 管理端 |
| 学员端 | `index.html#/` | 默认已登录演示学员「林晓」 |
| 登录 / 注册 | `#/login`、`#/register` | 账号密码已预填，可直接登录；验证码为原型模拟 |
| 管理后台 | `#/admin` | 未登录时显示后台登录页，账号密码已预填，直接点登录 |

> 管理后台演示账号：`admin` / `admin123`（表单已预填）

## 页面清单

### 学员端

- **首页**：继续练习、快捷入口、学习统计、近 7 天学习柱状图、待办、热门阶段、面试入口
- **题库中心**：顶部「学科题库 / 错题本」两个 Tab；学科题库按 8 个学科 → 阶段 → 顺序 / 随机练习
- **错题本（题库中心内）**：待复习 / 已掌握、连续答对 3 次自动掌握、手动标记、批量操作、单题重练
- **做题页**：单选、多选（漏选给部分分）、判断、简答（AI 判分模拟 + 采分点反馈）、答题卡、计时、交卷、结果页
- **学习路线**：路线进度、课程列表、站内「去学习」足迹记录、手动「标记已学」
- **AI 面试**：方向 / 难度 / 题量（3/5/8/10/15）配置、录音单独同意、文字 + 语音（模拟）作答、单题 5 分钟倒计时、提前结束
- **面试报告**：综合得分、能力雷达、逐题回顾、优势 / 不足 / 建议、同方向同难度历史对比、未考察维度标注
- **面试记录 / 回放**：历史报告、录音回放（模拟）
- **能力中心**：刷题雷达、面试雷达、综合雷达、六维明细与最弱项推荐
- **个人中心**：资料、修改密码、登录设备、通知设置、授权管理、注销账号
- **消息中心**：复核结果、报告生成等站内消息

### 管理后台

- **数据看板**：用户 / 学习 / 刷题 / 面试四组指标、7 日访问、学员分布、待审核题目、最新操作
- **学科管理**：8 个学科及阶段 / 题目 / 课程 / 路线统计
- **B站课程库**：课程列表、Excel 批量导入（模拟）、下载模板
- **刷题题库**：状态筛选（待审核 / 已上架 / 已驳回 / 已下架）、审核通过 / 驳回 / 下架 / 重新上架、新增 / 编辑题目（能力维度必填、简答题采分点与及格线）
- **面试题库**：按学科 / 难度筛选、审核上下架、从知识库导入
- **知识库**：按学科绑定、上传文档、按标题切题预览
- **学习路线**：路线列表、编辑引用课程
- **能力维度**：全局 6 个维度维护
- **维度映射**：维度 → 推荐课程 / 阶段
- **学员管理**：搜索、状态筛选、学员详情抽屉、禁用 / 启用、脱敏导出
- **批改复核**：简答题申诉复核、改分 / 维持原分、站内消息通知学员
- **用户管理**：后台账号、角色、启用 / 停用
- **角色权限**：3 个内置角色、25 个权限点、权限编辑
- **操作日志**：关键后台操作记录
- **系统设置**：基础信息、注册安全、AI 配额、数据保留、重置演示数据

## 原型中刻意保留的说明

- 简答题判分、语音识别、录音回放、Excel 导入均为**前端模拟**，页面内已标注「原型演示 / 模拟」
- 未做真实登录鉴权、接口请求、文件上传与服务端校验
- 面试录音、手机号脱敏、注销冷静期、数据保留策略等按需求文档以文案和交互流程呈现
- 页面底部与管理后台设置中均提供「重置演示数据」入口，可恢复初始状态

